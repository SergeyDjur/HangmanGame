Hangman - консольная игра виселица на java.

Чтобы запустить, игру откройте файл GameRunner в папке src и нажмите Run.

Когда игра запустится у пользователя будет выбор начать игру - нажать 1 и завершить игру - нажать 2.

Если пользователь запустите игру, то появится маска из символов '*' и состояние виселицы

Количество символов маски равно количеству букв в слове, которое вы должны отгадать.

После вы должны по одной букве отгадывать слово.

Допускается вводить только кириллицу и по одной букве за раз.

Если пользователь введет верную букву, то она отобразится в слове маске.

Если пользователь вернет букву, которой нет в слове, то отобразится следующая стадия виселицы.

Игра продолжается до тех пока пользователь не отгадает все буквы в слове или не допустит максимальное количество ошибок.

Максимальное количество ошибок, которое может допустить пользователь 6.

По окончании игры появляется поле ввода в котором пользователь может начать новую игру или закончить игры, как в начале игры.

Данный проект реализован для практической отработки базовых структур данных и типов данных на языке java.

Hangman console Hangman game in Java.

To run the game, open the GameRunner file in the src folder and click “Run”.

When the game starts, the user will see a choice: press 1 to start the game or press 2 to exit.

If the user starts the game, a mask made of * symbols will appear, along with the current state of the gallows.

The number of characters in the mask matches the number of letters in the word the player needs to guess.

Next, the player must guess the word one letter at a time.

Only Cyrillic letters are allowed, and only one letter can be entered per turn.

If the player enters a correct letter, it will be revealed in the masked word.

If the player enters a letter that is not in the word, the next stage of the gallows will be displayed.

The game continues until the player either guesses all the letters in the word or makes the maximum number of mistakes.

The maximum number of mistakes allowed is 6.

After the game ends, an input field appears where the player can choose to start a new game or finish playing, just like at the beginning of the game.
